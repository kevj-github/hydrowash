Three Booking Flows

Customer sees a different form depending on which category they select first

🔧 MAINTENANCE
General cleaning, chemical wash, etc. Contract-eligible.
Step 1
Select service type (filtered to MAINTENANCE only)
Number of units
Step 2
Date range — earliest + latest acceptable date
Preferred time slot (Morning / Afternoon / Evening)
Step 3
Address + postal code (geocoded + map pin)
Step 4
Notes (optional) + Review + Submit
→ Status: PENDING
→ Admin sees on map, groups with nearby bookings, approves with confirmed date
⚠️ FAULT REPAIR
AC not cooling, leaking, noisy. Urgent. No date picker.
Step 1
Select fault type (e.g. "Not Cooling", "Water Leaking", "Strange Noise", "Other")
Urgency: 🔴 High / 🟡 Medium / 🟢 Low
Step 2
Describe the fault in detail
Best time to call (Morning / Afternoon / Evening)
Step 3
Address + postal code
Step 4
Review + Submit
→ Status: INQUIRY
→ Admin sees under "Fault Inquiries" tab, calls customer directly
→ No scheduling flow — owner handles ad-hoc
📦 INSTALLATION
New AC unit install. Needs more detail. One-off job.
Step 1
Number of units to install
AC brand + model (optional if customer doesn't know yet)
Room type (Bedroom / Living Room / Office)
Step 2
Date range — earliest + latest acceptable date
Preferred time slot
Step 3
Address + postal code (geocoded)
Step 4
Notes + Review + Submit
→ Status: PENDING
→ Admin reviews details, may call customer to confirm unit specs before approving
Admin — updated bookings view

All Bookings
Maintenance tab: Map of pins. Owner visually clusters nearby requests. Selects a group → sets one confirmed date for all of them → bulk-approves. Each customer's date must fall within their requested range.
Fault Inquiries tab: List of inquiries with urgency badge. Owner clicks to see details + customer phone. No approve/reject — just "Mark Contacted" and "Mark Resolved".
Installation tab: Standard card list. Owner reviews specs, approves with a confirmed date within the customer's range.
