Three Booking Flows — Final

All three categories use date-range scheduling. Fault repair adds inspection-first logic.

🔧 MAINTENANCE
Cleaning, chemical wash, etc.
Step 1 — Service
Service type (maintenance only) · Number of units · Notes
Step 2 — Dates
Earliest acceptable date · Latest acceptable date · Preferred slot
Step 3 — Address
Address · Postal code · Geocode + map pin verify
Step 4 — Review + Submit
Summary → submit
→ Status: PENDING
→ Admin clusters on map, bulk-approves with one date
⚠️ FAULT REPAIR
Inspection first. Fix on-site or quote follow-up.
Step 1 — Fault Details
Fault type · Urgency (High / Medium / Low) · Description of the problem
Step 2 — Availability
Earliest date available · Latest date · Preferred time to be home
Step 3 — Address
Address · Postal code · Geocode + map pin
Step 4 — Review + Submit
Summary → submit
→ Status: PENDING
→ Admin approves inspection visit (HIGH urgency = prioritised)
→ Technician inspects: minor fix → COMPLETED
→ Major job → admin creates follow-up booking manually
📦 INSTALLATION
New AC unit. One-off. Needs more detail upfront.
Step 1 — Unit Details
Number of units · AC brand + model (optional) · Room type
Step 2 — Dates
Earliest date · Latest date · Preferred slot
Step 3 — Address
Address · Postal code · Geocode + map pin
Step 4 — Review + Submit
Notes · Summary → submit
→ Status: PENDING
→ Admin reviews unit specs (may call to confirm model)
→ Approves with confirmed date within range
Admin — Bookings Tabs
🗺 Maintenance (map + bulk-approve)
⚠️ Fault Repair (urgency-sorted)
📦 Installation
All
Maintenance: Map pins of all pending requests. Owner selects a geographic cluster → picks one confirmed date → bulk-approves. Only dates within each customer's range are valid.
Fault Repair: List sorted by urgency (High first). Each card shows fault description + customer phone. Owner approves for an inspection visit date (within customer's range).
Installation: Card list. Owner reviews AC details, approves with a confirmed date.
Fault Repair — after inspection:
✅ Minor fix done on-site → admin marks booking COMPLETED
🔧 Major repair needed → admin creates a new booking manually (linked to the same customer, category = FAULT_REPAIR, notes = "Follow-up repair from inspection on [date]") → new scheduling cycle begins
