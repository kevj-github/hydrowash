Tech Stack
Framework  Next.js 15 (App Router, TypeScript)
Database  Supabase (Postgres + Row Level Security)
Auth  Supabase Auth (customers + admin roles)
Maps  Google Maps Platform (Geocoding + Distance Matrix)
Email  Resend (React Email templates)
UI  Tailwind CSS + shadcn/ui
Optimization  Custom VRP (nearest-neighbour, runs on server)
Deployment  Vercel
Why one codebase works here: Singapore's typical load is 2–5 service cars, 5–15 jobs per day. The route optimization runs as a Next.js server action — no separate Python backend needed at this scale. Supabase handles auth for both customers and the admin owner, with role-based access via Row Level Security.
